
# Aula 09 — Consultas, Índices e Relatórios

## 📌 Sobre o projeto

Atividade de Banco de Dados utilizando MariaDB e o banco de dados `Pizzaria`, com o objetivo de praticar consultas SQL, criação de índices, views e manipulação de registros.

## 📂 Arquivos do projeto

- `script.sql` — criação do banco de dados, das tabelas e inserção dos dados iniciais.
- `queries.sql` — consultas SQL de A a F e comandos para inserir e atualizar clientes, pizzas e pedidos.
- `index.sql` — consultas na tabela Clientes e criação de índice para a coluna `nome`.
- `views.sql` — criação de views para consultar pedidos, clientes, pizzas, subtotais e totais.
- `README.md` — documentação do projeto.

## 📚 Conteúdos trabalhados

- SELECT, WHERE e LIKE
- SHOW TABLES e COUNT
- INNER JOIN
- SUM e GROUP BY
- Criação e consulta de índices
- Criação e consulta de views
- INSERT e UPDATE
- Cálculo de subtotais e totais de pedidos

## 🛠️ Tecnologias utilizadas

- MariaDB
- SQL
- Visual Studio Code

## ▶️ Como executar

1. Abra o MariaDB ou a ferramenta SQL utilizada nas aulas.
2. Execute o arquivo `script.sql` para criar e preencher o banco de dados.
3. Execute as consultas do arquivo `queries.sql`.
4. Execute o arquivo `index.sql` para testar as consultas e o índice.
5. Execute o arquivo `views.sql` para criar e consultar os relatórios.

> **Atenção:** o arquivo `script.sql` apaga e recria o banco de dados `Pizzaria`. Executá-lo novamente pode apagar os dados já cadastrados.

## 🎯 Objetivo

Praticar comandos SQL para consultar, organizar e manipular dados, além de utilizar índices e views para facilitar as buscas e a geração de relatórios em um banco de dados de uma pizzaria.
